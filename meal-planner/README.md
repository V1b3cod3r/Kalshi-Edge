# Meal Planner

A weekly meal plan plus an Amazon Fresh / Whole Foods shopping list, generated by Claude.

- **Stack**: Next.js 15 (App Router) + Tailwind + TypeScript
- **AI**: Anthropic Claude (Sonnet 4.6 by default)
- **Hosting**: Vercel free tier
- **Auth**: Single shared password
- **Cost**: ~$0.03–$0.06 per generated week with Sonnet 4.6

---

## How it works

1. You set dietary preferences (free text — treated as hard constraints) and a pantry list (staples you already own) on the **Settings** page.
2. **Generate plan** sends those, plus a serving count, to Claude in one call.
3. Claude returns 21 meals (Mon–Sun × breakfast/lunch/dinner). The server aggregates ingredients across the week into one shopping line per `(name, unit)`, skipping anything in your pantry.
4. The shopping list groups items by aisle. Each item has an **Open** button that pops a pre-filtered Amazon Fresh (or Whole Foods) search for that ingredient in a new tab — pick the right product, add to cart, then check it off.

### Why deeplinks instead of auto-add to cart?

Amazon has no public consumer API for adding grocery items to a cart. The two
realistic alternatives — browser automation and unofficial endpoints — are both
fragile and TOS-adjacent. Deeplinking is compliant, requires no Amazon
credentials, and degrades gracefully when Amazon changes its UI.

## Local development

```bash
cd meal-planner
npm install
cp .env.example .env.local
# Fill in ANTHROPIC_API_KEY, APP_PASSWORD, AUTH_SECRET
npm run dev
```

Open <http://localhost:3000>. Log in with `APP_PASSWORD`.

Generate a strong `AUTH_SECRET`:

```bash
openssl rand -hex 32
```

---

## Deploying to Vercel

1. Push this repo to GitHub.
2. <https://vercel.com/new> → import the repo.
3. **Root Directory**: `meal-planner`.
4. Environment variables: `ANTHROPIC_API_KEY`, `APP_PASSWORD`, `AUTH_SECRET`.
5. Deploy.

## Notes & limits

- Quantities are rounded sums per `(ingredient, unit)`. If the model uses two
  different units for the same ingredient (e.g. `2 cup spinach` and `100 g spinach`),
  they'll show as two lines. Edit the pantry/preferences if you want to nudge units.
- The shopping list opens **Amazon search results**, not specific products.
  Picking the right product (organic vs not, brand, size) is still on you.
- Refreshes are not cached — each "Regenerate" hits Claude. If you want variety
  across the week, just hit it again.
